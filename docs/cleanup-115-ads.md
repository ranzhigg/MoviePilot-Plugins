# 115 广告附件清理

[`scripts/cleanup_115_ads.py`](../scripts/cleanup_115_ads.py) 来自本地清理脚本的脱敏版本。目标目录改为必填参数，其余匹配、遍历和限速逻辑沿用本地实现。作为独立运维脚本保存，不随插件安装包自动执行。

## 使用

在已登录 115 存储的 MoviePilot V3 容器内，将脚本放到持久化目录后运行。以下目录仅为示例，请替换为实际云盘目录：

```bash
# 预览，不删除
/opt/venv/bin/python3 /config/agent/scripts/cleanup_115_ads.py --root '/整理/媒体'

# 删除命中的广告文本附件
/opt/venv/bin/python3 /config/agent/scripts/cleanup_115_ads.py --root '/整理/媒体' --delete

# 被 115 要求冷却后，等待一小时再执行
/opt/venv/bin/python3 /config/agent/scripts/cleanup_115_ads.py --root '/整理/媒体' --delete --cooldown 3600
```

## 匹配与保护

- 只处理 `.txt`、`.html`、`.htm`、`.url` 文件，视频、字幕和目录不删除
- 文件名经过 NFKC 规范化、去空白及零宽字符、常见繁简字归一，再匹配直播、收藏不迷路、最新位址、最新地址、聚合全网、社区最新、广告等关键词
- 不以网址或域名本身作为删除条件；这些是文件名启发式规则，不读取正文判定，普通文本也可能包含相关关键词，应先预览
- 递归遍历所有层级，按目录 ID 去重；使用 MP 存储接口分页列举
- 删除前复核路径对应的文件 ID、大小和广告匹配，删除后查询确认；不是原子操作，仍应避免同时移动或改名目标文件
- 本进程每次底层请求完成后至少间隔 3 秒再发起下一次请求；MP 内部重试和其他进程请求不受此节流控制，不能保证免于 115 限流
- 使用与本地旧脚本相同的锁，防止并发启动；报告在 `/config/temp/blacklist-cleanup/`，记录候选、删除、失败及最终统计
- 目录读取最多尝试 3 次，失败会记录并继续其他目录；有任何失败则返回非零。中断后重跑会重新扫描，不提供断点续扫

## 兼容与隐私

依赖当前 MP V3 的 `SystemConfigService` 和 `U115Pan` 内部接口，宿主更新后需复核兼容性。通过本机 `/config/user.db` 读取已有存储授权，不包含账号、Cookie、Token 或私人目录。脚本提供只读配置适配，若存储授权失效，请先在 MP 中恢复登录。

执行报告含云盘文件名和路径，仅在本地保存，不应上传公共仓库。此脚本规则独立于 115 插件的 `strm_generate_blacklist` 配置，不会自动修改插件实时黑名单。
