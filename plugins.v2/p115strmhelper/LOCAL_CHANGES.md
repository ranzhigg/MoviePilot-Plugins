# 本地修改快照

基于 DDSRem-Dev/MoviePilot-Plugins 的 P115StrmHelper 2.8.81，保留上游作者与许可证。本 fork 发布版本为 2.8.82，沿用现有 plugins.v2 目录，不迁移到 plugins.v3。

## 包含的修改

- 逐条通知已迁移到独立的 STRM逐条通知 插件，本插件不再内置该发送逻辑
- 黑名单命中后删除对应 115 云端文件，覆盖 API、全量、增量与生活事件路径；这是本地版本的实际行为，使用前需审阅黑名单配置
- 增量清理跳过目录且不计入删除数，保留目录内容；普通文件的关联清理仍受原设置控制
- 并发 API 端点冷却改为时间预约，避免多个线程同时唤醒造成请求突发
- Open API 429 重试遵循 Retry-After 并受 retry_limit 限制，避免持续限流时无限递归
- Redis 目录树比较和增量目录写入改为批处理，减少大媒体库的网络往返
- 分享 STRM 的 pickname 文件名遵循 STRM URL 编码配置，避免特殊字符破坏查询参数
- 302 跳转采用 inline，并保留与响应体一致的 JSON 类型
- 自愈脚本钩子改为环境变量 P115STRM_SELF_HEAL_SCRIPT，默认关闭；仅接受明确配置的绝对文件路径，私有运维脚本不随仓库发布
- 本地前端 dist 资源，以及三个用于 Linux ARM64 / CPython 3.14 的配套 wheel

## 脱敏范围

仅同步插件代码和必要资源，不包含运行配置、Cookie、Token、数据库、日志、缓存、备份、账号档案或私有运维脚本。自愈脚本原有本机路径已移除，个人操作口径改为中性注释。前端和 wheel 已纳入扫描；未修改的上游文件及上游历史仍保留。

## 使用边界

自愈脚本需由部署者自行提供并配置；不设置环境变量时不执行。版本号、仓库索引和发布安装包统一为 2.8.82。环境变量也可以保存在 MoviePilot 的 /config/app.env 中，真实脚本路径仅在部署端设置。
