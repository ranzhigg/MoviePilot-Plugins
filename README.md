# MoviePilot-Plugins

> 个人维护的 MoviePilot 插件仓库。

## 保留插件

### STRM 逐条通知

- [V3 插件](plugins.v3/strmnotify)：监控新增 STRM，等待 NFO/封面就绪后逐条发送媒体通知，支持持久化去重。

## 插件索引

- package.v3.json：MoviePilot V3 插件索引。

MoviePilot 插件市场支持通过 PLUGIN_MARKET 添加本仓库；仓库仅支持 GitHub main 分支。
